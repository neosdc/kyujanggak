CANDIDATES

실행 엔진과 모델을 함께 고릅니다.

우선 검증첫 비교 대상조건 확인언어·라이선스·지연 제약
Vosk를 고른다면

선택한 언어 모델 하나를 유지하세요.

vosk-model-small-ko-0.22
vosk-model-small-en-us-0.15

후보 어휘를 명령 목록으로 제한할 수 있습니다. 다만 목록에 단어를 넣는 것만으로 모델 어휘에 없는 단어를 학습하지는 않습니다.

두 언어 모델을 동시에 돌리면 자원 사용과 결과 판정이 복잡해집니다. 위 두 소형 모델은 Apache 2.0 라이선스입니다.

SenseVoice를 고른다면

모델은 한 번 로드하고, 발화마다 재사용하세요.

sherpa-onnx
+ sense-voice-zh-en-ja-ko-yue INT8

모델의 언어를 auto로 지정하거나 ko / en으로 고정할 수 있습니다. 자동 판별과 한영 혼합 인식은 다른 문제입니다.

공식 가중치는 별도 FunASR 모델 라이선스입니다. 조건 준수 시 상업적 사용이 허용되며 변환 파일의 조건도 확인해야 합니다.

하드웨어와 배포 시 확인할 조건

SenseVoice 초기 검토 기준: 64비트 Linux와 RAM 2GB 이상을 여유 기준으로 권장합니다. 공식 최소 요구량이 아니며 CPU 성능을 보장하지 않습니다.

완전 오프라인 배포: 실행 파일, 모델, 토큰 파일, VAD 모델을 기기에 미리 넣고 로컬 경로로 로드합니다. SDK의 자동 다운로드에 의존하지 않도록 구성합니다.

라이선스 구분: 엔진 코드의 라이선스와 모델 가중치의 라이선스는 다를 수 있습니다. Moonshine 영어 모델의 MIT 조건을 현재 한국어 모델에 적용하면 안 됩니다.

ON-DEVICE PIPELINE

STT 결과를 허용된 명령으로 연결합니다.

표현은 여러 개, 실행 명령은 하나

“불 켜”“조명 켜줘”“turn on the light”
LIGHT_ON

공백·문장부호 등을 정리한 뒤, 사전에 정한 표현을 같은 명령으로 연결합니다.

명령이 소수로 고정되어 있다면 키워드 인식도 후보입니다. 직접 학습한 작은 분류 모델은 범용 STT보다 자원을 줄일 수 있지만, 한국어·영어 음성과 미등록 발화 데이터를 준비해야 합니다.

READ THE NUMBERS

파일 크기, RAM, 응답 속도는 다릅니다.

메모리 숫자를 해석하는 방법

Vosk: 한국어 약 82MB, 영어 약 40MB는 모델 다운로드 크기입니다. 실행 RAM 약 300MB는 소형 모델에 대한 일반 안내이며, 한국어 모델이나 두 모델 동시 실행의 보장 수치가 아닙니다.

SenseVoice: 약 228MiB는 공식 문서의 INT8 모델 파일 크기입니다. 운영체제·런타임·오디오 버퍼·앱이 사용하는 메모리는 별도입니다.

Whisper: tiny 약 273MB, base 약 388MB는 whisper.cpp의 공식 메모리 안내입니다. 양자화 방식과 실행 조건에 따라 달라질 수 있으며 CPU 지연은 별도입니다.

NEXT DECISION

같은 명령 녹음으로 두 후보를 비교하세요.

Vosk와 SenseVoice INT8에 같은 음성을 입력합니다. 정상 명령 외에도 주변 대화, 소음, 무음, 목록에 없는 표현을 넣습니다.

명령 성공률말한 명령이 의도한 기능으로 연결되는가
잘못된 실행률다른 명령이나 일반 대화를 오인하지 않는가
발화 후 지연말을 끝낸 시점부터 동작까지 얼마나 걸리는가
최대 자원 사용앱과 함께 실행할 때 RAM·CPU에 여유가 있는가

현재 권장: 자원 절약과 언어 선택이 가능하면 Vosk, 한국어·영어를 한 모델에서 자동 처리해야 하면 sherpa-onnx + SenseVoice INT8부터 시작합니다. 최종 선택은 목표 보드에서의 명령 성공률과 지연으로 결정합니다.
