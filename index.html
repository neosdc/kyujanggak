  • HTML Modular Monolith 업무 모듈의 공개 계약·데이터 소유권·의존성 경계를 유지하면서 하나의 애플리케이션으로 배포하는 구조

  • HTML 이벤트 기반 아키텍처(EDA) 이벤트 발행·구독, Outbox, 중복·순서·실패 처리와 업무 완료 기준을 설명한 가이드
  • HTML Hexagonal Architecture Port와 Adapter로 업무 핵심을 UI·DB·메시지 등 외부 기술과 연결하는 구조

  • HTML Clean Architecture Dependency Rule과 Use Case 경계로 핵심 업무 규칙을 외부 기술에서 보호하는 구조

  • HTML SSH 역방향 터널 내부 웹 서비스를 클라우드 VM의 Nginx와 SSH 역방향 터널로 공개하는 구성·보안·운영 노트
